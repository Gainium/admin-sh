## Decisions

- One origin stays a string rather than a one-element array, so the
  response for single-address installs is byte-for-byte the same (§4.2).
- Legacy tier: none beyond lifting the parse into a pure function — the
  only touched code is these six lines.

2. No `core/` submodule in this repo.
3. Owned contracts (CLAUDE.md "OWNS/EMITS": Redis `admin-config`, REST
   routes) are untouched; only the CORS response header changes, and only
